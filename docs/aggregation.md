# Anonymous aggregation

Public aggregates are derived statistics, not a pseudonymised dump of user-level financial records.

Only users who have not opted out may contribute to future aggregate generation. Public queries require a minimum cohort size; the current UI threshold is 20.

Paused, closed and abandoned strategy instances should remain eligible for historical cohort calculations so community results do not silently acquire survivorship bias.

Canonical model series remain separate from user implementation aggregates. Account returns must not be naively averaged.
